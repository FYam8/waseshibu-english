# 早稲渋 英語｜過去問 × 弱点克服

2019〜2026年度の早稲田渋谷シンガポール校・英語入試をベースにした GitHub Pages 向け静的アプリです。

## 今回の設計

### PDFビューアは使いません
実際の問題冊子PDFをアプリ内表示する方式はやめました。
問題冊子から抽出した **実際の筆記本文・設問** を、アプリの画面にテキストとして収録しています。

### 過去問を解いた後が本体
1. 実際の過去問を解く
2. 公式解答で採点
3. 誤答を分野・A/B・原因で記録
4. 同じ技能の類題を反復
5. **3問連続正解** まで続ける
6. 翌日に **2問連続正解** の定着チェック
7. ここまで通れば「克服済み」

間違えると連続正解数は0に戻るため、「たまたま1回当たった」で弱点を消しません。

毎日の必須課題はA問題を優先して最大3弱点です。割当を終えた後は同じ日に課題を自動補充せず、残りは次回以降へ回します。翌日確認は予定日前に開始できません。

## 弱点ドリル対象
- 発音
- アクセント
- 語句整序
- 言い換え
- 文脈
- 心情
- 理由
- 本文抜出
- 内容一致
- 英語完成
- 指示語
- 接続語
- 文挿入
- 内容把握
- 具体例
- 短文完成
- 要約
- 要約＋反論

通常の英単語学習・リスニングは別アプリ想定です。

## 得点戦略
- A：60点を守るため最優先。誤答は必ず克服ドリルへ。
- B：65〜75点への上積み。
- C：時間がかかる問題は後回し。

## データ保存
ブラウザの `localStorage` に保存します。サーバー・ログイン不要です。保存キーは今後のバージョンでも変更せず、`schemaVersion` ごとの自動移行で学習履歴を引き継ぎます。旧版データは初回起動時に自動移行し、移行前データも移行元バージョン別の復旧用コピーとして端末内に残します。

## GitHub Pages
1. ZIPを展開
2. GitHubの公開リポジトリへ全ファイルをアップロード
3. `Settings` → `Pages`
4. `Deploy from a branch`
5. `main` / `(root)`

ビルド不要です。

## 修正案（別承認対象、未適用）

最小の優先対象は2022:6-2および同poolを使う接続語弱点。次の差分を教材・選問の候補として扱う。

1. 例示・対比・原因結果・追加を区別する接続関係の問題を、即時3family＋翌日2familyに分けられる量で用意する。既存rdt_cx03は同じIDで維持し、別内容へ使い回さない。新問は新IDとし、既存connector類題の再利用可否を意味内容で先に調べる。
2. 当該focusに5family確保できた場合のみ、学校側のpool選択でそのfocusを優先する案を作る。既存3+2、旧問題、旧答案・得点・masteryを変更しない。共有Engineを無断改変しない。
3. 開始済みcurrentDrill、reservedConfirm、seenDrillsは途中交換しない。旧予約を保持するセッションの扱いと新規開始への適用境界を明示して回帰検査する。過去masteredを取り消したり再計算したりしない。
4. 合格条件は接続語の即時3問と翌日2問が重複familyなしで確保されること、例示を別文脈で自力説明できる確認課題を含むこと。後者の人の能力は本人の答案で別評価する。

現時点で不足を隠すために会話問題を接続語問題へラベル変更しない。全問書換え・習得閾値の緩和・同じ1問の反復で埋めない。監査指示第4/7/12節により、意味・分類・学習進行の変更は根拠と履歴影響を示した別承認対象。
